# Proyecto Multibase (Sistema de Biblioteca)

API RESTful desarrollada en Node.js y Express que integra múltiples bases de datos (PostgreSQL, MongoDB y Redis).

## Tecnologías utilizadas
- Node.js & Express
- PostgreSQL
- MongoDB
- Redis

---

## Instrucciones de Instalación y Ejecución

### 1. Clonar el repositorio
```bash
git clone [https://github.com/dianaweasleymc-web/Proyecto--multibase.git](https://github.com/dianaweasleymc-web/Proyecto--multibase.git)
cd Proyecto--multibase

### 2. Instalar las dependencias
npm install
### 3. Configuración de Bases de Datos
* **PostgreSQL:** Ejecuta los scripts SQL incluidos en el repositorio para la estructura y datos iniciales. 
* **MongoDB & Redis:** Asegúrate de tener ambos servicios corriendo de forma local en sus puertos predeterminados.

### 4. Ejecutar el proyecto
npm run dev
